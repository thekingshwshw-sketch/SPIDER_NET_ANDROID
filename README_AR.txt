SPIDER NET SMART ACCOUNTING SYSTEM — Android WebView project

المحتويات:
- app/src/main/assets/index.html: نسخة النظام الحالية مدمجة داخل التطبيق.
- مشروع Android Gradle لتغليف النظام كتطبيق Android.
- GitHub Actions workflow لبناء APK تجريبي (Debug APK).

مهم:
1) هذا الأرشيف هو ملفات مصدر مشروع Android وليس APK جاهزًا للتثبيت.
2) لم يتم تجميع APK داخل بيئة العمل الحالية لعدم توفر Android SDK/Gradle مثبت محليًا.
3) لبناء APK: ارفع محتويات المجلد إلى مستودع GitHub جديد، ثم افتح Actions وشغّل Build Android APK (أو انتظر البناء بعد push). نزّل artifact باسم SPIDER-NET-Accounting-APK، ثم استخرج app-debug.apk.
4) هذه نسخة جديدة: بيانات المتصفح داخل التطبيق تبدأ فارغة عند أول تشغيل. لا تستورد نسخة JSON قديمة إذا أردت البدء من الصفر.
5) بيانات النظام تُخزَّن محليًا داخل WebView على الهاتف. حذف التطبيق أو مسح بياناته قد يحذف السجلات؛ صدّر نسخة JSON بانتظام.
6) لا ترفع ملفات JSON التي تحتوي على ديون أو بيانات نقاط البيع إلى مستودع عام.
7) قبل الاعتماد التجاري، اختبر إضافة سجل، إغلاق التطبيق وإعادة فتحه، والتصدير والاستعادة على الهاتف.
